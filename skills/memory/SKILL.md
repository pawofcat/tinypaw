# 记忆技能 (Memory)

## 描述
帮助用户记录和管理重要信息，支持长期记忆和短期笔记。

## 触发条件
- 用户说"记住..."、"记下来"、"添加到记忆"
- 用户询问之前提到过的内容
- 用户提到"我的笔记"、"之前的记录"

## 工具
- `memory_search` - 搜索记忆内容
- `memory_get` - 读取记忆文件
- `memory_append` - 追加记忆内容

## 使用示例

### 记录信息
```
用户：记住明天下午 3 点开会
助手：好的，已记录到今日记忆中。
```

### 检索信息
```
用户：我之前说过什么关于项目的事？
助手：让我搜索一下... 找到了，你在 3 月 10 日提到项目需要在月底前完成。
```

## 记忆文件格式

记忆保存在 `memory/YYYY-MM-DD.md` 文件中，按日期组织。

```markdown
# 2026-03-11

## 重要事项
- 明天下午 3 点开会

## 笔记
- 项目进度：完成 80%
```
